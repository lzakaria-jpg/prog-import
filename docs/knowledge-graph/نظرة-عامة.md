# نظرة عامة — prog-import

تطبيق React/Vite داخلي لفريق تنفيذ الأنظمة المحاسبية بقيود (Qoyod) — يجهّز ملفات العملاء غير المنظمة ويرسلها/يصدّرها بصيغة قيود، عبر سبع أدوات مستقلة تحت واجهة واحدة (`src/App.jsx`).

هذه الملاحظة مبنية يدويًا من الكود الفعلي الحالي (وليست من مخرجات graphify المرفوعة على `master` — تلك كانت قديمة جدًا وممزوجة بمكتبات خارجية مثل pdf.js وExcelJS المبنّتة داخل `public/old/`، فاستُبعدت).

## الفكرة العامة لكل أداة
ملف عميل غير منظم (Excel/CSV) → ربط أعمدة (تلقائي + تعديل يدوي) → تحقق/مطابقة ببيانات المنشأة الحقيقية (عبر API) → تصدير قالب قيود الرسمي و/أو إرسال مباشر عبر REST API. كل أداة تدعم عدة تبويبات لعدة عملاء بنفس الوقت (راجع [[التبويبات-المتعددة]]).
