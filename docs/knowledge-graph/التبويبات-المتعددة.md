# التبويبات المتعددة (TabbedTool)

**الملف:** `src/lib/TabbedTool.jsx`

غلاف مشترك يُستخدم بكل الأدوات السبع — يتيح فتح عدة عملاء بنفس الأداة بنفس الوقت، ويبقي كل تبويب حيًا (`display:none` بدل إلغاء التركيب) عشان عمليات الإرسال الجارية عبر API ما تتوقف عند تبديل التبويب أو الخروج لأداة ثانية.

كل أداة تحتاج فقط: مكون جذر `forwardRef` يكشف `{ requestStop }`، وprops مثل `onNameChange`/`onBusyChange` — راجع نمطها بـ[[أداة-فواتير-المشتريات]] (`QoyodBillImport.jsx`) والأدوات اللي قلّدته.
