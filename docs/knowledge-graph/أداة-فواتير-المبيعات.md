# مطابقة واستيراد فواتير المبيعات (Sales Invoice Import)

**المفتاح:** `tool.sales` · **المجلد:** `src/sales-invoice-import/`

ترسل فواتير المبيعات عبر `POST /sales_invoices`، مع فارق جوهري عن المشتريات: شجرة الحسابات تُغني عن رفع ملف عند نجاح الجلب عبر API.

## ملفات مهمة
- `api/qoyodSalesRefFetch.js` — جلب عملاء/منتجات/ضرائب/مشاريع/مخزون مرجعية (`buildCustomersIndexFromApi`, `buildProductsIndexFromApi`…).
- منطق دفع الفاتورة عبر [[طبقة-الشبكة-والـAPI]].
