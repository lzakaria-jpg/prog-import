# أداة استيراد فواتير المبيعات (Sales Invoice Import)

**المفتاح:** `tool.sales` · **المجلد:** `src/sales-invoice-import/`

نفس فلسفة [[أداة-فواتير-المشتريات]] (POST /sales_invoices بدل /bills)، مع فارق جوهري: شجرة الحسابات تُغني عن رفع ملف عند نجاح الجلب عبر API (بخلاف فواتير المشتريات اللي القالب فيها يبقى إلزاميًا حتى مع API).

## ملفات مهمة
- `api/qoyodSalesRefFetch.js` — جلب عملاء/منتجات/ضرائب/مشاريع/مخزون مرجعية (`buildCustomersIndexFromApi`, `buildProjectsIndexFromApi`...).
- منطق دفع الفاتورة عبر [[طبقة-الشبكة-والـAPI]].
