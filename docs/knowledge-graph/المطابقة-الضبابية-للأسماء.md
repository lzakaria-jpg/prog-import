# المطابقة الضبابية للأسماء (Fuzzy Name Matching)

**الملف:** `src/lib/excelCore.js` — `accountNameSimilarity(left, right)` + `normalizeAccountName(value)`

خوارزمية تطبيع/تشابه عربية واحدة يُعاد استخدامها بكل مكان يحتاج مطابقة أسماء متقاربة (رغم اسمها "Account"، عامة تمامًا):
- تطبيع: إزالة التشكيل، توحيد الألف/الهمزة، التاء المربوطة، الألف المقصورة.
- التشابه: أعلى قيمة بين تشابه الكلمات المشتركة ومسافة Levenshtein المعكوسة.
- **العتبة المعتمدة بكل المشروع: 0.85** (أول استخدام: [[أداة-شجرة-الحسابات]]، `MergeTool.jsx`).

## من يستخدمها
- [[أداة-شجرة-الحسابات]] — دمج حسابات متقاربة الاسم بين شجرتين.
- [[أداة-العملاء]] و[[أداة-الموردين]] — كشف تكرار الاسم مع تجريد كلمات كيان قانوني إضافية (`lib/duplicateMatch.js`).
