# الصلاحيات والأدوار

**الملف:** `src/lib/permissions.js`

ثلاثة أدوار: `owner` (كل شيء دومًا)، `full_user_manager` (إدارة مستخدمين كاملة)، `user` (فقط ما يُمنح صراحة). صلاحيات الأدوات مصفوفة مسطّحة `TOOL_PERMISSIONS` — كل مفتاح جديد (`tool.customers`, `tool.vendors`...) يظهر تلقائيًا بلوحة الإدارة (`auth.jsx`) بلا أي عمل إضافي.

`can(user, key)` هي بوابة الإنفاذ الوحيدة — تُستدعى من `src/App.jsx` (`AppShell`) لتقرير أي أداة تُركَّب (mount) فعليًا، لا فقط تُخفى بـCSS.
