# مرجع Qoyod API

مصدرا الحقيقة الوحيدان لأي قرار متعلق بحقول/أنواع Qoyod الرسمية — أي تخمين ممنوع، يُرجَع لهما دومًا:

- `config/qoyod-openapi-v2.1.yaml` — مواصفة REST API الكاملة (9045 سطرًا): كل endpoint، كل حقل، كل قيد تحقق موثَّق حرفيًا (مثال: الرقم الضريبي 15 رقمًا يبدأ وينتهي بـ3، الهاتف 966+ و12 رقمًا).
- `config/qoyod-account-types-reference.json` — 59 نوع حساب رسمي لتصنيف شجرة الحسابات.

## قيد مؤكَّد مهم
لا حقل "رقم مرجعي" (Ref. No.) موثَّق إطلاقًا لـ`/customers` أو `/vendors` — لا بالإرسال ولا بالاستجابة (`ContactResponse`). قرار التعامل مع هذا موثَّق بـ[[أداة-العملاء]].
