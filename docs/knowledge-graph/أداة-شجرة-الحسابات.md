# أداة شجرة الحسابات (Merge)

**المفتاح:** `tool.merge` · **الملف الرئيسي:** `src/MergeTool.jsx`

تحلل وتدمج شجرة حسابات عميل مع القالب الرسمي لقيود — تشتق `parent_kind`/`branch_kind` من المرجع الرسمي، تستبعد الحسابات المقفلة نظاميًا (المدينون/الدائنون...) من الإرسال، وتكتشف الأب تلقائيًا للحسابات بلا كود/أب عبر مطابقة الحسابات الموجودة فعلًا بالمنشأة (API).

## يعتمد على
- `src/lib/excelCore.js` — [[المطابقة-الضبابية-للأسماء]] (`accountNameSimilarity`, عتبة 0.85) لمطابقة/دمج الحسابات المتقاربة الاسم.
- `src/lib/qoyodAccountSync.js` / `qoyodAccountPush.js` — إرسال عبر [[طبقة-الشبكة-والـAPI]].
- `config/qoyod-account-types-reference.json` — [[مرجع-Qoyod-API]] (59 نوع حساب، مصدر الحقيقة الوحيد للتصنيف).
