# طبقة الشبكة والـAPI

**الملف:** `src/product-upload/io/network.js`

طبقة الاتصال الوحيدة الموصى بها بقيود — تُستورَد مباشرة من كل أداة جديدة بدل إعادة تنفيذها محليًا (القرار المتبع بأداتي [[أداة-العملاء]] و[[أداة-الموردين]]).

- `api(method, path, body, apiKey)` — عبر `/api/qoyod-proxy` (وكيل CORS، `functions/api/qoyod-proxy/[[path]].js`، لا يُخزّن المفتاح إطلاقًا).
- `fetchAll(path, apiKey)` — ترقيم صفحات تلقائي، يعامل 404 كقائمة فارغة (وليس خطأ)، يستخرج المصفوفة الخام مباشرة لو بلا مفتاح جذر (مثل `/projects`).
- محدّد معدل مشترك على مستوى الوحدة (module-level): 300 طلب/60 ثانية — يُطبَّق تلقائيًا على أي أداة تستورد هذا الملف، بلا تنسيق يدوي.
