# أداة استيراد فواتير المشتريات (Bill Import)

**المفتاح:** `tool.bills` · **المجلد:** `src/bill-import/`

المعمارية المرجعية التي بُنيت عليها أدوات لاحقة عدة ([[أداة-العملاء]]، [[أداة-الموردين]]): خطّاف واحد (`useImportEngine.js`) يحمل كل الحالة والمنطق، مكونات عرض فقط (`components/`)، أربع خطوات (اتصال → ربط أعمدة → مراجعة → تصدير/إرسال).

## البنية (نمط يُقلَّد حرفيًا بأدوات أخرى)
- `lib/fields.js` + `lib/mapping.js` (`autoMap`) — ربط أعمدة تلقائي بالاسم وشكل القيم معًا.
- `lib/clientFile.js` — قراءة الملف وبناء الصفوف (مجمَّعة بالفاتورة عبر `groupsOf`).
- `lib/validation.js` — كل قواعد تحقق قيود (السعر مع وحدة التحويل، الخصم، التواريخ...).
- `lib/billsPush.js` — إرسال مباشر عبر `POST /bills` باستخدام [[طبقة-الشبكة-والـAPI]].
- `lib/template.js` — قراءة/كتابة القالب عبر JSZip (يحافظ على التنسيق والقوائم المنسدلة).
