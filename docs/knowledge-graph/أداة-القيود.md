# مطابقة واستيراد القيود المحاسبية (Journal)

**المفتاح:** `tool.journal` · **الملف الرئيسي:** `src/JournalTool.jsx`

تحلل قيودًا محاسبية من ملف عميل غير منظم (بما فيها قالب "دفتر القيود" الرسمي لقيود بأعمدة الموقع/المشروع الأربعة الصريحة)، تتحقق من هيكلها، وترسلها عبر `POST /journal_entries`.

## نقاط مهمة
- المشروع (`project_id`) والموقع (`inventory_id`) قد يردان على مستوى القيد أو مستوى السطر أو كلاهما معًا — منطق الاشتقاق والتمييز بين المستويين في `src/lib/excelCore.js` (`guessEntriesColumnMapping`, `parseEntriesFileWithMapping`).
- `src/lib/qoyodJournalRefFetch.js` يجلب شجرة الحسابات + عملاء/موردين مرجعيين + مشاريع + مواقع مباشرة عبر API بدل رفعها يدويًا (`fetchJournalReferencesFromApi`).
- `src/lib/qoyodJournalEntryPush.js` — الإرسال الفعلي عبر [[طبقة-الشبكة-والـAPI]].
