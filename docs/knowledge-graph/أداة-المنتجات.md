# أداة رفع المنتجات إلى قيود (Product Upload)

**المفتاح:** `tool.products` · **المجلد:** `src/product-upload/`

ترفع منتجات العميل مباشرة عبر API (`POST /products`، وينشئ الفئات/الوحدات المفقودة تلقائيًا عند الحاجة).

## أهم ملف بالمشروع كله
`src/product-upload/io/network.js` — طبقة [[طبقة-الشبكة-والـAPI]] المشتركة فعليًا بين كل الأدوات (`api()`, `fetchAll()`) — أي أداة تستوردها ترث محدّد المعدل (rate limiter) نفسه تلقائيًا.
