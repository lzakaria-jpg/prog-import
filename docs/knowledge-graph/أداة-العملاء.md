# أداة استيراد العملاء (Customer Import)

**المفتاح:** `tool.customers` · **المجلد:** `src/customer-import/` · أُضيفت 2026-09-16

تجهّز وتنشئ عملاء العميل عبر `POST/PUT /customers`، بنفس بنية [[أداة-فواتير-المشتريات]] لكن بلا تجميع فواتير — كل صف بالملف = سجل عميل مستقل.

## قرارات تصميم مهمة
- **الرقم المرجعي (Ref. No.):** لا حقل موثَّق له إطلاقًا بمواصفة Qoyod OpenAPI (لا بالإرسال ولا بالقراءة، راجع [[مرجع-Qoyod-API]]) — تصحيح مباشر من المستخدم أوضح أن `custom_fields` **ليس** بديلاً صحيحًا له (حقل مختلف تمامًا يُعرَّف يدويًا بالإعدادات). الحل النهائي (`lib/refSuggest.js`): الرقم المرجعي محلي لنطاق الملف فقط، لا يُرسَل عبر API إطلاقًا، يُكتب في ملف القالب المُصدَّر فقط.
- **كشف التكرار (`lib/duplicateMatch.js`):** يعيد استخدام [[المطابقة-الضبابية-للأسماء]] (عتبة 0.85) + تجريد كلمات كيان قانوني ("شركة"/"مؤسسة") قبل المقارنة.
- **التحقق:** الهاتف (966+ و12 رقمًا)، الرقم الضريبي (15 رقمًا يبدأ وينتهي بـ3) — مطابقان حرفيًا لمواصفة Qoyod.
- القالب الرسمي مرفق كأصل ثنائي (`assets/customer_import_template.xlsx`) — لا حاجة لرفعه يدويًا.
