# مطابقة واستيراد العملاء (Customer Import)

**المفتاح:** `tool.customers` · **المجلد:** `src/customer-import/` · أُضيفت 2026-09-16

تطابق أسماء العملاء مع الموجودين بالمنشأة، ثم تنشئ/تحدّث عبر `POST/PUT /customers`. سطر واحد بالملف = عميل واحد.

## قرارات تصميم مهمة
- **الرقم المرجعي (Ref. No.):** لا حقل موثَّق له إطلاقًا بمواصفة Qoyod OpenAPI (لا إرسالًا ولا قراءةً — راجع [[مرجع-Qoyod-API]]). الحل (`lib/refSuggest.js`): محلي لنطاق الملف فقط، يُكتب بملف القالب المُصدَّر ولا يُرسَل عبر API.
- **كشف التكرار (`lib/duplicateMatch.js`):** [[المطابقة-الضبابية-للأسماء]] بعتبة 0.85 + تجريد كلمات الكيان القانوني ("شركة"/"مؤسسة") قبل المقارنة.
- **الأداء:** فهرس جهات الاتصال يُبنى مرة واحدة، وتعديل خانة يعيد فحص صفها وحده (737ms ← 1.09ms لكل ضغطة زر).
- **التحقق:** الهاتف (966 + 12 خانة)، الرقم الضريبي (15 خانة تبدأ وتنتهي بـ3).
