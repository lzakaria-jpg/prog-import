# أدوات قيود — مدقق القيود + بناء شجرة الحسابات (PWA مستقل)

تطبيق ويب مستقل (خارج بيئة Claude بالكامل) فيه أداتين بتبويبين:
1. **استيراد القيود** — فحص وتجهيز ملفات القيود المحاسبية
2. **استيراد الشجرة** — قراءة شجرة حسابات العميل (Excel، PDF، أو Word) وبناء شجرة متوافقة مع قيود

## خبر مهم: كلا الأداتين تعملان الآن بدون أي تكلفة أو إعداد إضافي

**تبويب "استيراد الشجرة" لم يعد يحتاج ذكاء اصطناعي أو مفتاح API إطلاقاً.** يعتمد على:
- تصنيف محاسبي ثابت (كل نوع من الـ59 نوع له تصنيف أب طبيعي بين الـ12 نوع — هذه معرفة محاسبية عامة، ثابتة بالكود)
- قاموس كلمات مفتاحية (مرادفات) لمطابقة أسماء حسابات العميل بأي صيغة كتبها بها

أي حساب ما قدرت الأداة تطابقه بثقة يظهر برمز مبدئي (يبدأ بـ 9) بدون نوع محدد — تراجعه وتختار نوعه يدويًا من القائمة
المنسدلة (موجودة أصلاً بالجدول القابل للتعديل). دقة المطابقة تعتمد على قرب تسمية العميل من المصطلحات المحاسبية
المعتادة؛ حدّث قاموس المرادفات في `src/lib/accountsClassifier.js` كلما لاحظت أسماء متكررة ما تتطابق صح.

**تبويب "استيراد القيود" فيه ميزة إضافية اختيارية** ("المراجعة الذكية") تحتاج فعلاً مفتاح Anthropic API — هذه وحدها
تحتاج الإعداد الموصوف بالأسفل. الفحوصات الحاسمة (التوازن، الحساب الرئيسي، الرمز الموجود، صيغة التاريخ) تعمل بدون أي
إعداد إطلاقاً.

## النشر البسيط (يكفي للأداتين، بدون ميزة المراجعة الذكية الاختيارية)

استخدم ملف `qoyod-pwa-dist-جاهز-للرفع.zip` واسحبه لـ https://app.netlify.com/drop — كل شي رح يشتغل، بما فيها بناء
شجرة الحسابات الكامل، بدون أي حساب GitHub أو مفتاح API.

## لو حبيت لاحقاً تفعّل "المراجعة الذكية" الاختيارية بأداة القيود

هذه الميزة وحدها تحتاج دالة خادم (Netlify Function) تحمل مفتاح Anthropic API بأمان. Netlify Drop لا يشغّل دوال
خادم، فلازم تنشر عبر GitHub بدل ذلك:

1. أنشئ حساب GitHub مجاني (إذا ما عندك): https://github.com/signup
2. أنشئ مستودع (Repository) جديد فاضي
3. **استخدم GitHub Desktop** (https://desktop.github.com) لرفع المشروع — الرفع من المتصفح مباشرة يفكك بنية
   المجلدات أحياناً؛ Clone الريبو الفاضي، انسخ محتويات `qoyod-pwa-source-كامل` (بعد فك الضغط) جوا المجلد، ثم
   Commit و Push
4. اذهب لـ https://app.netlify.com → "Add new site" → "Import an existing project" → اختر GitHub → اختر المستودع
5. Netlify يكتشف تلقائياً إعدادات البناء من `netlify.toml` — اضغط Deploy
6. من Site configuration → Environment variables → أضف `ANTHROPIC_API_KEY` بمفتاحك من
   https://console.anthropic.com (يحتاج إضافة وسيلة دفع — لا يوجد مستوى مجاني مستمر لهذه الخدمة)
7. Trigger deploy مرة أخرى عشان يقرأ المتغير الجديد

## التشغيل محلياً (للتجربة)

```bash
npm install
npm run dev
```

## البناء اليدوي

```bash
npm install
npm run build
```

## تثبيت الأيقونة على الجوال

**أندرويد (كروم):** افتح الرابط ← القائمة (⋮) ← "إضافة إلى الشاشة الرئيسية"
**آيفون (سفاري):** افتح الرابط ← زر المشاركة (□↑) ← "إضافة إلى الشاشة الرئيسية"

## تحديث قالب قيود الرسمي مستقبلاً

استبدل `public/qoyod_template.xlsx` بالنسخة الجديدة، أعد البناء، وأعد الرفع.

## تحسين دقة مطابقة أسماء الحسابات

قاموس المرادفات بملف `src/lib/accountsClassifier.js` (كائن `SYNONYMS`) — أضف أي كلمات شائعة لاحظت إنها ما بتتطابق
صح مع النوع الصحيح، بدون الحاجة لإعادة بناء أي شي معقد.
